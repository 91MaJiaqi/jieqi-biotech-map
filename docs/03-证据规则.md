# 03 · 证据规则

## 1. 为什么必须区分「传统经验」与「现代科学机制」

二十四节气是长期农业生产实践中形成的**经验性时间体系**（已列入联合国教科文组织人类非物质文化遗产代表作名录），
而生物技术是**机制驱动的现代科学工具**。两者可靠性来源不同：

- 传统经验：来自长期观察与口传，可能有效，但缺乏机制解释，对地区、品种、年份敏感。
- 现代科学机制：来自可重复验证的研究，机制清晰，但仍有适用条件边界。

平台上每条关系都带 `nature` 字段，取值为 **传统经验** 或 **现代科学机制**，
前端在节气详情页、农事建议页都会把两者**分栏呈现**，避免读者把农谚当作科学结论。

## 2. 证据等级

| 等级 | 判定标准 | 典型来源 |
| --- | --- | --- |
| **强** | 有权威标准、定稿科普或可核验研究支撑，机制清晰、结论稳定 | UNESCO 名录、农业农村部科普、中科院研究所科普、科普中国定稿条目 |
| **中** | 有较可靠来源或领域通行观点，但受地区/品种/年份条件影响 | 专家意见、农业气象通识、机构科普栏目 |
| **弱** | 主要来自民间经验或单一非权威来源，缺乏机制支撑 | 农谚 |
| **待验证** | 来源不足或为演示数据，尚未核验 | 示例条目 |

**农谚一律记为「弱」。** 平台不引用未经核验的论文原文与古籍原文。

## 3. 来源类型

| 来源类型 | 说明 |
| --- | --- |
| 古籍 | 古代农书文献。本项目未引用具体古籍原文（无法核验版本者不写入）。 |
| 农谚 | 民间口传经验，无单一权威出处，统一「弱」证据。 |
| 论文 | 学术研究结论。种子数据中仅用于中科院研究所等公开科普所转述的结论。 |
| 标准 | 国家/行业标准或权威机构的正式科普定稿。 |
| 专家意见 | 领域专家通行观点，用于机制解释与方向性判断。 |
| 示例 | 项目构造的演示数据，**不得用于生产决策**。 |

## 4. 置信度（confidence）

- 取值范围 0~1，仅用于列表排序（图谱、建议、区域关系的排序）。
- **不等价于证据等级**：例如「强证据 + 地区泛化差」可能置信度不高；反之亦然。
- 前端在关系行中显式展示该数值，保证可解释。

## 5. 合规约束（工程上如何保证）

1. `seed.validate()` 在导入时校验每条关系的 `evidence_level` 与 `source_type` 是否在允许集合内，
   非法取值会计入 `problems` 并在 `/api/seed-report` 暴露；pytest 中亦有用例断言。
2. 所有科普链接必须命中权威域名白名单，否则导入即报错。
3. 平台不采集受版权保护的数据；科普链接一律指向原始权威页面。
4. 所有面向生产的建议输出都附带免责声明字段 `disclaimer`，前端固定渲染：
   **「以上建议仅供参考，不替代当地农技部门指导。」**

## 6. 用户如何自查

- 任意详情页与知识卡片 → 点击「权威科普」区块的链接跳转原站核对。
- `/about` 页面 → 证据等级规则、来源类型、关系类型、已收录证据清单。
- `/api/seed-report` → 服务端校验报告（应为 `problems: []`）。
