## 4. 链接维护建议

- 机构站点改版可能导致 URL 失效。若发现 404，请将其替换为新页面，或降级为对应栏目首页，并在本文件更新记录。
- 更新后务必运行 `python -m pytest -q`：若新链接不在白名单域名内，测试会失败。
- 前端所有外链均带 `target="_blank" rel="noopener noreferrer"`，避免反向导航与安全风险。
