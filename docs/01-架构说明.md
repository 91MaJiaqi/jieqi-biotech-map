# 01 · 架构说明

## 1. 总体结构

```
浏览器（React SPA）
   │  fetch /api/*
   ▼
反代（开发：Vite proxy；生产：Nginx location /api/）
   │
   ▼
FastAPI（backend/app/main.py）
   ├── routers/catalog.py     实体编目接口
   ├── routers/knowledge.py   图谱 / 检索 / 建议 / 气候 / 证据
   ├── logic.py               业务逻辑（图谱构建、建议生成、气候示意模型）
   ├── models.py              SQLModel 数据模型
   ├── seed.py                种子加载 + 服务端校验
   └── database.py            引擎与会话
   │
   ▼
SQLite（默认，文件 jieqi.db）—— 预留 PostgreSQL / Neo4j 适配
```

## 2. 后端分层

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 入口 | `app/main.py` | 创建 FastAPI 应用、注册 CORS、挂载路由、`lifespan` 中建表并首次导入种子数据 |
| 模型 | `app/models.py` | 8 张表：`terms` `techs` `organisms` `genes` `environments` `regions` `relations` `evidences` |
| 存储 | `app/database.py` | `DATABASE_URL` 决定引擎；SQLite 关闭 `check_same_thread` |
| 种子 | `app/seed.py` | 读取 `data/seed.json`；校验链接域名、关系端点存在性、证据等级/来源类型合法性；幂等导入 |
| 逻辑 | `app/logic.py` | 节点索引、图谱过滤、跨实体检索、建议生成、气候示意模型 |
| 路由 | `app/routers/*.py` | HTTP 契约、参数校验（`Query`/`HTTPException`） |

**设计原则**：路由层只做参数与响应，业务规则集中在 `logic.py`，便于单测与后续替换存储。

## 3. 图谱的 MVP 实现

- 需求允许 MVP 用「SQLite + JSON 关系表」，因此关系以 `relations` 表存储，`source_id` / `target_id` 指向任意实体 id。
- `logic.build_node_index()` 在每次请求时把 6 类实体合并成 `id -> 节点` 的索引，把关系翻译为边，返回给前端 ECharts 力导图。
- 后续接入 Neo4j 时，只需替换 `build_graph()` 的实现，保持返回结构 `{nodes, links, stats}` 不变，前端无需改动（适配层思路）。

## 4. 前端结构

- **路由**：`react-router-dom`，`App.tsx` 集中声明页面路由，`Layout.tsx` 提供导航与页脚免责声明。
- **数据获取**：`src/hooks.ts` 的 `useAsync` 统一处理 `loading / error / data`；`src/api/client.ts` 定义全部类型与请求函数。
- **图表**：
  - 二十四节气圆盘 → 手写 SVG（`SeasonDisk.tsx`），按 `(huangjing - 315 + 360) % 360` 排序定角，季节着色；
  - 关系图谱 → `echarts-for-react` 力导图（`RelationGraph.tsx`），点击节点按类型跳转；
  - 气候偏移 → ECharts 横向条形图；
  - 地域 → `react-leaflet` 地图（`RegionMap.tsx`，使用 `divIcon` 避免默认图标资源缺失）。
- **科普区块**：`ScienceLinkBlock.tsx` 是唯一渲染权威科普链接的组件，所有详情页与知识卡片复用，保证外链属性一致。

## 5. 关键交互链路

1. 首页 → 圆盘点击节气 → `/term/:id` → 展示物候/气候/农谚 + 权威科普 + 关系证据。
2. `/graph` → 三个下拉筛选 → `GET /api/graph` → 力导图渲染 → 点击节点 → 对应详情页。
3. `/advice` → 三个下拉 → `GET /api/advice` → 建议 / 风险 / 技术 / 传统 vs 现代。
4. `/climate` → 滑块 → `GET /api/climate?delta=` → 偏移图表 + 应对技术。

## 6. 错误处理

- 后端：实体不存在返回 `404`，参数越界（如 `delta>4`）由 FastAPI 返回 `422`。
- 前端：`useAsync` 捕获异常并展示错误文案；`apiGet` 对非 2xx 抛出具名错误；图谱空结果给出引导提示。
