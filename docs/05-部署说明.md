# 05 · 部署说明

## 1. 本地开发部署（推荐用于验收）

### 后端

```bash
cd backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

- 首次启动自动建表并导入 `data/seed.json`。
- SQLite 文件默认位于仓库根目录 `jieqi.db`；可用环境变量覆盖：
  `DATABASE_URL=sqlite:///D:/data/jieqi.db`。

### 前端

```bash
cd frontend
npm install
npm run dev        # http://127.0.0.1:5173
```

Vite 已配置 `server.proxy['/api'] → http://127.0.0.1:8000`，无需处理跨域。

### 生产构建 / 本地预览

```bash
cd frontend
npm run build      # 先 tsc 类型检查，再 vite build
npm run preview    # http://127.0.0.1:4173
```

## 2. Docker Compose 部署

```bash
docker compose up --build
```

| 服务 | 容器端口 | 宿主机端口 | 说明 |
| --- | --- | --- | --- |
| frontend | 80 | 8080 | Nginx 托管 `dist/`，`/api`、`/docs`、`/openapi.json` 反代到 backend |
| backend | 8000 | 8000 | uvicorn 运行 FastAPI，SQLite 数据存于卷 `jieqi-data` |

访问：<http://localhost:8080>（前端）、<http://localhost:8000/docs>（接口文档）。

### 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | `sqlite:///(repo)/jieqi.db` | 后端数据库连接串 |
| `CORS_ORIGINS` | 本地 5173/4173 | 允许的跨域来源，逗号分隔 |

## 3. 切换 PostgreSQL

1. 安装驱动：`pip install "psycopg[binary]"`（容器镜像需一并加入 `requirements.txt`）。
2. 设置 `DATABASE_URL=postgresql+psycopg://user:pass@host:5432/dbname`。
3. 取消 `docker-compose.yml` 中 `postgres` 服务的注释并相应调整 `DATABASE_URL`。

> 说明：模型层使用 SQLModel/SQLAlchemy，切换到 PostgreSQL 无需改代码；但本项目**未在 PostgreSQL 上实测**，
> 属预留能力，见 [06-已知限制与假设.md](06-已知限制与假设.md)。

## 4. 接入 Neo4j（预留）

MVP 使用「SQLite + 关系表」实现图谱。若关系规模增长，建议：

1. 启动 compose 中注释的 `neo4j` 服务。
2. 编写导入脚本，把 `relations` 表写为 `(:A)-[:解释|指导|突破|适应|案例]->(:B)`。
3. 重写 `app/logic.py::build_graph()`，保持返回结构 `{nodes, links, stats}` 不变 —— 前端零改动。

## 5. 反向代理与静态托管

`frontend/nginx.conf` 已包含：

- `try_files $uri $uri/ /index.html`：支持 React Router 的 history 模式（刷新不 404）。
- `location /api/`、`/docs`、`/openapi.json` 反代到 `http://backend:8000`。
- 开启 gzip。

## 6. 无 Docker 环境的替代方案

本项目已在**未安装 Docker 的 Windows 环境**下用「uvicorn + vite」方式完整实测通过
（后端 pytest 23 项、前端 Playwright 10 项全部通过）。因此验收时若不满足 Docker 依赖，
可直接采用第 1 节流程，功能行为一致。
`docker-compose.yml` 与两个 `Dockerfile` 作为交付物保留，供具备 Docker 的环境一键启动。

## 7. Playwright 浏览器获取

Playwright 默认使用自带 Chromium（`npx playwright install chromium`，约 200 MB）。
若下载受限，可复用系统已安装的 Edge / Chrome，无需任何下载：

```bash
cd frontend
PW_CHANNEL=msedge npm run test:e2e      # Windows 自带 Edge
PW_CHANNEL=chrome  npm run test:e2e     # 已安装 Chrome
```

`playwright.config.ts` 通过环境变量 `PW_CHANNEL` 切换浏览器通道，未设置时回退到自带 Chromium。
