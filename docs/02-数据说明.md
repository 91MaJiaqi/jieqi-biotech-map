# 02 · 数据说明

## 1. 数据来源与形态

- 唯一数据源：`data/seed.json`。
- 首次启动时由 `app/seed.py` 导入 SQLite；数据库中已有数据则跳过（幂等）。
- 需要重新导入时：删除仓库根目录 `jieqi.db` 后重启，或调用 `seed_database(force=True)`。

## 2. 实体清单

| 实体 | 表名 | 数量 | 关键字段 |
| --- | --- | --- | --- |
| Term 节气 | `terms` | 24 | id、name、huangjing（黄经）、date、season、phenology、climate、proverb、url、url_title |
| Tech 生物技术 | `techs` | 12 | id、name、category、description、scenarios、url、url_title |
| Organism 生物对象 | `organisms` | 10 | id、name、type（作物/畜禽/水产）、url、url_title |
| Gene 基因 | `genes` | 5 | id、name、function、organism、url、url_title |
| Environment 环境因子 | `environments` | 5 | id、name、unit、effect、url、url_title |
| Region 地区 | `regions` | 5 | id、name、climate_zone、crops、url、url_title |
| Relation 关系 | `relations` | 26 | source_id、target_id、type、description、nature、evidence_level、source_type、source_ref、region、season、confidence |
| Evidence 证据 | `evidences` | 9 | id、title、source_type、citation、level、note |

**每个可展示实体都带 `url` + `url_title`**，这是需求中的硬性要求，由 `seed.validate()` 强制校验。

## 3. 节气数据

24 节气按太阳黄经排列，`huangjing` 取标准值：立春 315°、春分 0°、夏至 90°、秋分 180°、冬至 270°，
相邻节气间隔 15°。`phenology` 采用「三候」概括，`climate` 为季节气候特征概述，二者属常规气象/物候常识表述。

`proverb` 为民间流传农谚，全部按「弱」证据处理，见 [03-证据规则.md](03-证据规则.md)。

## 4. 关系数据（核心）

关系是平台的知识主体，字段含义：

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `type` | 解释 / 指导 / 突破 / 适应 / 案例 | 关系语义类别，对应图谱边着色 |
| `nature` | 传统经验 / 现代科学机制 | **强制区分**，同一对实体可同时存在两类 |
| `evidence_level` | 强 / 中 / 弱 / 待验证 | 证据等级 |
| `source_type` | 古籍 / 农谚 / 论文 / 标准 / 专家意见 / 示例 | 来源类型 |
| `source_ref` | 自由文本 | 可核验的依据描述 |
| `region` / `season` | 地区 / 季节 | 用于建议与图谱过滤 |
| `confidence` | 0~1 | 置信度，用于排序（不与证据等级等价） |

### 典型关系示例

- `秋分 → 冬小麦`：指导，传统经验，证据「中」，来源类型「农谚」。
- `冬小麦 → VRN1`：解释，现代科学机制，证据「强」，来源类型「论文」。
- `VRN1 → 分子标记辅助育种`：突破，现代科学机制，证据「中」。
- `惊蛰 → 生物农药`：指导，传统经验，证据「中」。
- `棉花 → Bt基因`：案例，现代科学机制，证据「强」，来源类型「标准」。

## 5. 校验规则（`seed.validate()`）

导入前与测试中都会执行，任何一条不满足即计入 `problems`：

1. 所有实体的 `url` 主机名必须命中 `meta.allowed_domains` 白名单（含子域匹配）。
2. 实体 `id` 不得重复。
3. 关系的 `source_id` / `target_id` 必须指向已存在的实体。
4. `evidence_level` ∈ {强, 中, 弱, 待验证}，`source_type` ∈ {古籍, 农谚, 论文, 标准, 专家意见, 示例}。

校验结果通过 `GET /api/seed-report` 暴露，便于运维自检。

## 6. 数据规模说明

- 关系 26 条，满足「≥20 条节气—生物技术关系」要求。按关系类型：指导 8、突破 6、适应 5、案例 4、解释 3。
- 按性质：现代科学机制 18 条、传统经验 8 条；按证据等级：中 17、强 5、弱 2、待验证 2。
- 关系覆盖到的实体：节气 10 个、生物技术 8 项、作物/生物 9 种、基因 4 个、环境因子 4 个、地区 1 个。
- 环境因子共 5 个（温度、光照、降水、积温、土壤pH）、基因共 5 个（VRN1、VRN-D4、Bt、耐旱相关 DREB 类、抗病相关 NBS-LRR 类）。
- 未覆盖的节气/技术并非缺失，而是**未找到可核验的来源**，因此不写入数据，避免编造。
